## КРИТИЧЕСКИЕ БАГИ (необходимо исправить)

### Bug 1: Хардкод строки `"name"` вместо переменной `name`

**Файл:** `src/ru/rsreu/morozov/datalayer/postgresql/PostgreSubscriptionDAO.java:44`

```java
statement.setString(1, "name");   // БАГ: передаёт литерал "name", а не переменную name
```

**Исправление:** заменить `"name"` на `name`:
```java
statement.setString(1, name);
```

**Последствия:** каждая подписка будет называться "name", вторая вставка упадёт с UNIQUE constraint violation.

### Bug 2: Отсутствует `getLabelDAO()` в фабрике

**Файлы:**
- `src/ru/rsreu/morozov/datalayer/DAOFactory.java` — нет abstract метода `getLabelDAO()`
- `src/ru/rsreu/morozov/datalayer/postgresql/PostgreDAOFactory.java` — нет реализации `getLabelDAO()`

**Исправление:** добавить в `DAOFactory.java`:
```java
abstract public LabelDAO getLabelDAO();
```

И в `PostgreDAOFactory.java`:
```java
@Override
public LabelDAO getLabelDAO() {
    return new PostgreLabelDAO(this.connection);
}
```

**Последствия:** `LabelDAO` полностью реализован, но получить его экземпляр через фабрику невозможно.

## УМЕРЕННЫЙ БАГ

### Bug 3: Broken double-checked locking в PostgreDAOFactory

**Файл:** `src/ru/rsreu/morozov/datalayer/postgresql/PostgreDAOFactory.java:22-29`

Отсутствует внутренняя проверка `instance == null` внутри `synchronized` блока. При конкурентном доступе возможно создание второго экземпляра с утечкой первого соединения.

**Исправление:**
```java
if (PostgreDAOFactory.instance == null) {
    synchronized (PostgreDAOFactory.class) {
        if (PostgreDAOFactory.instance == null) {  // <-- добавить
            PostgreDAOFactory.instance = new PostgreDAOFactory();
            factory = PostgreDAOFactory.instance;
            factory.connected();
        }
    }
}
```
